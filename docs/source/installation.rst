##############
 Installation
##############

The most recent release can be installed from `PyPI
<https://pypi.org/project/pubmed_classifier>`_ with uv:

.. code-block:: console

    $ uv pip install pubmed_classifier

or with pip:

.. code-block:: console

    $ python3 -m pip install pubmed_classifier

*********************
 Installing from git
*********************

The most recent code and data can be installed directly from GitHub with uv:

.. code-block:: console

    $ uv pip install git+https://github.com/cthoyt/pubmed-classifier.git

or with pip:

.. code-block:: console

    $ python3 -m pip install git+https://github.com/cthoyt/pubmed-classifier.git

****************************
 Installing for development
****************************

To install in development mode with uv:

.. code-block:: console

    $ git clone git+https://github.com/cthoyt/pubmed-classifier.git
    $ cd pubmed-classifier
    $ uv pip install -e .

or with pip:

.. code-block:: console

    $ python3 -m pip install -e .
